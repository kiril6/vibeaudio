outcome-aware

Three chimes, three meanings.

Ctrl+C is silent on purpose — an aborted run is never reported as done.

seeded, not random

Your repo, your sound.

Your working directory seeds the arrangement — the seed picks among hand-written, in-key progressions, it never invents harmony. Same repo, same sound, every time you come back.

Want one project to sound different on purpose? vibe --genre zen --here saves a genre for that directory and everything under it, leaving your default alone.

pick your integration

Hooks, wrapper, or MCP.

Recommended

Agent hooks

Music starts the moment you submit a prompt, stops the moment the agent finishes. No grace-window guessing. For Claude Code, Codex, Cursor, Grok, Gemini CLI, Copilot CLI, Qwen Code.

The wrapper

vibe <command> times the process itself. Right for anything that exits when its work is done — vibe npm test, one-shot agent calls, CI.

MCP

For clients with no hook system — Claude Desktop, Antigravity. The assistant decides to call vibe_play, so it's a suggestion, not a guarantee.

features

The details that keep it out of the way.

Grace window

Fast commands stay silent — music starts only past 1.5s.

Escalating tiers

Layers build as the agent digs deeper into a turn.

Honest exit codes

vibe claude && deploy behaves exactly like without the wrapper.

Title-bar HUD

A live waveform in the terminal title — never corrupts a full-screen TUI.

Pauses for permission

A rising "your turn" chime when the agent is stuck on you.

Mute for calls

vibe --mute — expires in an hour so you never forget it's on.

Reactive mode

vibe --reactive --install-hooks — intensity follows the tool in use, not just elapsed time. Opt-in, and the one setting that needs a reinstall to change.

Zero deps

Pure Node.js synthesis. No native bindings, no audio assets.

Several sessions

Music plays while any terminal is working and builds as more join; each gets its own chime.

Esc stops it

Interrupt the agent and the music goes quiet — an abort is never "done".

Errors sound different

An API error or rate limit plays the failure chime, not success.

Safe install

--dry-run previews the change; your other hooks are never touched.

get started

Four commands.

1

Install globally.

npm i -g vibeaudio
2

Wire it into your agent's hooks.

vibe --install-hooks
3

Audition a genre before committing.

vibe --preview jazz
4

Keep the one you liked. Installed hooks pick it up on your next prompt — nothing to reinstall.

vibe --genre jazz --volume 25
